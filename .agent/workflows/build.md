# Build for Production

Build the project and create optimized production files.

## Steps

// turbo
1. Run the build command:
```bash
npm run build
```

2. The output will be in the `dist/` directory

3. To preview the production build locally:
```bash
npm run preview
```

## Notes
- Production files are minified and optimized
- Check the `dist/` folder for the generated assets
