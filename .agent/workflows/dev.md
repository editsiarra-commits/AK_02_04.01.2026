# Start Development Server

Start the Vite development server for local development with hot reload.

## Steps

// turbo
1. Run the development server:
```bash
npm run dev
```

2. Open the browser at http://localhost:5173 (default Vite port)

## Notes
- The server will automatically reload when you make changes
- Press `Ctrl+C` to stop the server
